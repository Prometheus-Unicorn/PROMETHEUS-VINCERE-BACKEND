# Unlazy: Anti-Laziness, Depth-Tree, & Acceptance-Gate Protocol

The **Unlazy Protocol** forces AI agents to confront root causes, reject cookie-cutter template fallbacks, and verify every layer of execution through empirical evidence rather than superficial plausibility.

## Core Rules

1. **Reject Phantom Completeness:** Never claim a task or feature is complete when it relies on hardcoded strings, canned regex templates, stub mocks, or unverified presets.
2. **Expose Canned Patterns:** If an output looks generic, repetitive, or "baked in", trace it directly to the exact source (e.g. rigid regex triggers, static dictionaries, template libraries) and explain why the pipeline defaulted to it instead of dynamic editorial intuition.
3. **The Depth Tree Method:**
   - Layer 0: Surface symptom / generic output observation.
   - Layer 1: Code-level realization (where the hardcoded template or heuristic lives).
   - Layer 2: Pipeline decision path (why that specific heuristic was triggered over alternative paths).
   - Layer 3: Architectural root cause (the architectural gap between heuristic template matching and true generative short-form intelligence).
4. **Verifiable Acceptance Gates:**
   - Every claim must cite the exact file, line numbers, and causal mechanism.
   - No evasion, no sugar-coating, no defending canned slop as "cinematic".
