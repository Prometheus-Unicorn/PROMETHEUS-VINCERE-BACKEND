# Google Flow & Generative Video Ingestion Directory

Drop your Google Flow / Veo 3.1 / AI-generated video clips directly into this folder!

### Filename Mappings:
* **Beat 1** (`00:04 - 00:12` - Radical Self-Reliance): Name file `I001.mp4` or `beat1.mp4`
* **Beat 2** (`00:15 - 00:24` - The Research Mode Trap): Name file `I002.mp4` or `beat2.mp4`
* **Beat 3** (`00:25 - 00:36` - 100-Experiment Asymmetry): Name file `I003.mp4`, `I004.mp4`, or `beat3.mp4`

### Automatic Pipeline Detection:
When clips are placed here, running:
```powershell
python mini_run_pipeline/cinematic_asset_compositor.py
```
will automatically:
1. Detect each video clip.
2. Embed the footage into the **Polarizing Bevel / Card Elevation** container with evidentiary badge styling.
3. Apply the exact asset introduction mechanics (**3D Off-Axis Swing**, **Slap-Drop with Contact Bounce**, **Lateral Friction Slide**, **Background Defocus Isolation**).
4. Composite it into the master video with dialogue audio multiplexing.
